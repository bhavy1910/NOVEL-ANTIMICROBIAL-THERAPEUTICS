# NOVEL-ANTIMICROBIAL-THERAPEUTICS

A cinematic, interactive scientific presentation platform exploring next-generation approaches to combat antimicrobial resistance (AMR): bacteriophage therapy, antimicrobial peptides (AMPs), CRISPR-Cas antibacterial targeting, anti-virulence inhibitors, and precision nano-therapeutics.

## 🚀 Features

- **Interactive Scientific Video Showcase**: Embedded foreground visual and audio presentation with responsive controls.
- **Deep Scientific Slide Decks**:
  - Antimicrobial Resistance (AMR) Crisis & Global Burden
  - Bacteriophage Therapy Mechanisms & Clinical Trials
  - Antimicrobial Peptides (AMPs) & Membrane Disruption
  - CRISPR-Cas Antibacterial Precision Targeting
  - Anti-Virulence Strategies & Biofilm Disruption
  - Nanotechnology & Target Drug Delivery Systems
- **Interactive Pharmacokinetics & Mechanism Explorers**: Real-time interactive models and scientific parameters.
- **Responsive & Modern UI**: Built with React, TypeScript, Tailwind CSS, and Lucide Icons.

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Asset Pipeline**: Custom media integration with MP4 foreground playback

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/bhavy1910/NOVEL-ANTIMICROBIAL-THERAPEUTICS.git
cd NOVEL-ANTIMICROBIAL-THERAPEUTICS

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
